# TDK Guncel Turkce Sozluk, live per-entry API (sozluk.gov.tr)

**What it is and claims.** Per-entry verification turns the calque list into something nobody can argue with: fokuslanmak is an entry that redirects to odaklanmak; realizasyon redirects to gerceklestirme; adreslemek and implemente return no entry at all; soz konusu is an adjective meaning the thing being discussed.

**How it changes the skill.** A calque claim becomes either the dictionary has this and sends it here, or the dictionary does not have this word - both checkable in one query.

**Quality.** Primary institutional source, not peer-reviewed; for the book and the guides this is the field's standing authority.
