# tezgah logo

The mark is a 2.5D workbench: an amber worktop (the `t` crossbar) carried by a
single ink support (the `t` stem), with five small blocks on the top. The five
blocks are the hosts tezgah drives; the one bench is the shared contract they
all run under. The four ink blocks plus the teal one read as "four adapters and
one accent, one workbench".

Flat-shaded isometric, three tones per material, no gradients or bevels.

## Files

| File | Use |
|---|---|
| `tezgah-logo.svg` | Primary mark, full colour. |
| `tezgah-logo-mono.svg` | Single-ink version for stamps, embossing, one-colour print. |
| `tezgah-logo-*.png` | Raster previews at 512 / 256 / 64 / 32 / 16 px. |
| `tezgah-logo-mono-256.png` | Raster preview of the mono mark. |

## Notes

- The SVG is native vector geometry (`<polygon>` only), viewBox `0 0 512 512`,
  transparent background, with `<title>`, `<desc>`, `role="img"` and
  `aria-label` so the mark is machine-readable.
- Works down to 32 px. At 16 px the isometric diagonal softens; use the mono
  mark or a plain favicon when a crisp 16 px icon is required.
