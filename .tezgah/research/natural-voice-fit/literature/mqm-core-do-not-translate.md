# MQM-Core error typology: do not translate, untranslated, terminology

**What it is and claims.** The scoreable classes for this axis, stated in both directions. Under Accuracy, Do not translate is a marked segment being translated (their example: a Japanese translation of Apple Computers), and Untranslated is a segment intended for translation left as it was. Under Terminology: inconsistent with a terminology resource (their example: French rendering e-mail as e-mail where the resource mandates courriel), inconsistent use of terminology, and wrong term (river as riviere where fleuve is required). Locale conventions carry a shortcut-key error. The core is stated to be consistent with ISO 5060.

**How it changes the skill.** Both failure directions get a name and a severity, so the skill's own checks can be written in the industry's terms instead of in adjectives, and a reviewer can see which error a draft makes.

**Quality.** Formal: a standard, a peer-reviewed paper or an institutional framework.
