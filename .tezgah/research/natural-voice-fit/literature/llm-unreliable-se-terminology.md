# LLMs have an unreliable understanding of software engineering terminology (arXiv 2607.06004)

**What it is and claims.** The paper prompts models with correct and systematically falsified definitions from ISO/IEC/IEEE 24765:2017 (Systems and Software Engineering - Vocabulary), with semantic falsifications (key terms substituted) and structural ones, and finds that state-of-the-art models cannot reliably tell them apart. The paper's own framing names the cost: miscommunication both when a model reads text and when a human acts on model-written text.

**How it changes the skill.** The strongest evidence for the no-translate axis in the developer register: a model asked to render standardised terminology into another language is rewriting text whose definitions it cannot reliably check. The skill must protect the term, and this is why.

**Quality.** Formal: an arXiv record with an OpenAlex record; read as abstract in session.
