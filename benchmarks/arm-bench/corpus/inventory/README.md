# inventory

A tiny stdlib-only inventory library used as a coding-agent benchmark fixture.

- `inventory/core.py` - totals, discounts, lookups
- `inventory/pricing.py` - line and bulk pricing
- `inventory/parsing.py` - input parsing
- `inventory/report.py` - text reports

Run the tests with:

```sh
python3 -m unittest discover -s tests -q
```
