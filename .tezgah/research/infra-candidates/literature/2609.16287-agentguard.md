# AgentGuard: Learning Execution Guardrails from Anomalous Coding-Agent Trajectories

- id: alphaXiv 2609.16287 (AAAI 2027 preprint), 2026-09-14
- authors: Wuyang Dai, Song Wang (York University, Lassonde School of Engineering)
- url: https://www.alphaxiv.org/abs/2609.16287
- read: alphaXiv report + abstract, 2026-09-19

## Claim

Task success does not imply reliable execution: an agent can pass while modifying
unrelated files, rewriting tests, issuing unsafe commands, or ignoring failed
validations. AgentGuard learns *instruction-level* guardrails from historical
failure traces instead of hand-writing rule sets:

1. extract recurring execution-failure patterns from anomalous trajectories,
2. generalise them into instruction-level behavioral constraints,
3. ship them as a lightweight skill that dynamically activates only the rules
   relevant to the current instruction.

An *abnormal execution* is one that violates task scope, repository/environment
integrity, safe recovery, validation, artifact, or evidence-grounded reporting.

## Measured result

642 documented failure traces from real coding-agent runs across 382 repository
tasks; guardrails learned from 461 traces / 282 tasks, evaluated on a disjoint
100 tasks. Claude Code with Claude Haiku 4.5, baseline vs. +AgentGuard:

- abnormal execution rate: **69.0% → 26.7%**
- successful task completion: **21.7% → 35.0%**

They also cite the prior result (Zhang et al. 2026) that **negative behavioral
constraints outperform prescriptive guidance** for coding agents, and name the
open problem as balancing restriction against completion.

## Why it matters here

Two separable ideas, and tezgah is positioned differently on each:

- **Learned-from-traces rules.** tezgah has the *ingredients* - a per-session
  JSONL ledger with `deny` rows grouped by rule, and a `.tezgah/lessons.md`
  ledger that is written by hand when the user flags a mistake - and no pipeline
  joining them. AgentGuard is the closest published version of the missing loop,
  and it reports a 42-point drop in abnormal execution from it.
- **Dynamic activation.** tezgah already does this: `classify_prompt`
  (`hooks/tezgah_context.py:466`) arms a conditional paragraph per turn. AgentGuard
  independently validates the design, and its skill form is the same shape as
  tezgah's on-demand `CONTRACT`.

The completion-cost warning matters: their task completion is 21.7% even on the
baseline, so a 42-point abnormal-execution drop came at a real completion cost
in their setup. Any tezgah rule added under this heading must be measured on both
axes (adherence AND the corpus pass rate), which is what arm-bench already does.
