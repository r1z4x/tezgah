# feature-audit — Ustam `/users` (panel user administration)

Applied skill: `tezgah/skills/feature-audit/SKILL.md` (read 2026-09-21).
Target revision: `Ustam@98f985f` ("revert(admin): drop the duplicate h1 on the users surface"), read 2026-09-21. Worktree clean at read time.
Scope: read-only on `apps/admin` and `apps/api`; no project build or test suite was run (arm constraint).
Baseline for "the running app": not available to this arm (Docker is assigned to another agent), so no surface was exercised. Every finding below is a **reading** except F-17, which is a measurement of a stand-in fixture; that is stated where it is used.

## The unit

| | |
|---|---|
| Entity | A person's **membership** in the panel's own organization (a `User` + its `Membership`/`MembershipRole`). |
| Actions | invite, change role, change record scope, deactivate (membership inactive), reactivate, change display name / locale (self-service only by contract), list, search, filter by membership state, view a member's detail, sort, export, resend an invitation, read a member's audit trail. |
| Screens | `app/(dashboard)/users/page.tsx` (list + invite modal + per-row access modal). No other route exists under `users/` (`glob app/(dashboard)/users/**` → `page.tsx`, `user-labels.ts`, `actions.ts`, two test files). |
| Endpoints | `GET /api/v1/users`, `GET /api/v1/users/roles`, `GET /api/v1/users/{id}`, `POST /api/v1/users/invite`, `PATCH /api/v1/users/{id}`, `POST /api/v1/users/{id}/deactivate` (`users.controller.ts:36-90`; `docs/openapi.json:5858-5973`). |
| Sibling surfaces | mobile `apps/mobile/src/features/users/OrganizationUsersScreen.tsx` + `organization-users-api.ts:38-56` (same three mutations, different client). Read for the cross-surface rows only. |

Evidence classes (`user-verbatim`, `behaviour`, `ui-observed`, `code`, `external`). A finding without one would be a question; every row below carries one.

## Passes

Three passes, from three entry points, all by reading:

1. **API client with no UI** — controller, service, OpenAPI document, absence searches (`grep` over `apps/api/src`, `apps/mobile/src`, `apps/admin/{app,lib,components}`, `apps/admin/e2e`).
2. **Daily operator** — list, filters, row actions, both modals, success/failure paths end to end from source, plus the assertions the repo already makes about them (`page.test.tsx`, `actions.test.ts`, `e2e/admin-core-recovery.e2e.ts`, `e2e/admin-state-recovery.e2e.ts`).
3. **First-time user** — the invite flow's states, empty/error/loading states, headings, tab title, and one narrow-width measurement (F-17).

No pass exercised the running app: the state table in §Coverage records what that leaves unread.
