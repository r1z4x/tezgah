# Volansky, Ordan and Wintner, on the features of translationese (Digital Scholarship in the Humanities 30(1))

**What it is and claims.** A supervised-learning test of the proposed translationese universals: some feature sets are good indicators and others perform at chance, so several of the received universals have to be reconsidered.

**How it changes the skill.** The honest caveat for the marker leg: a marker family that works in one language is not automatically a universal, so each one is a claim to be measured rather than a rule to be copied.

**Quality.** Formal: a standard, a peer-reviewed paper or an academic-press record.
