# Personas Differ from Native-Language Generation (2608.30873)

**What it is.** A study of how persona conditioning and the language a model reasons
in shape the interpersonal advice it produces.

**What it claims.** Persona-conditioned generation differs from native-language
generation: the language pathway itself changes the output, so asking for a persona
in English and writing in Turkish is not the same as generating the persona's voice
inside the target language.

**What it gives us.** The mechanism our audience-brief hypothesis (H2) rests on, and
its main risk: a register brief written in English can flatten the target language's
own register. The brief should therefore name the target language's register markers,
not only the role.

**How it would change the skill.** The audience section carries per-language register
markers (Turkish `siz`/`sen`, title and address conventions, sector vocabulary)
rather than one English register description applied everywhere.
