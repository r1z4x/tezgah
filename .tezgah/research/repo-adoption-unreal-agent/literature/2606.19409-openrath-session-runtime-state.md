## What it gives

The design thesis, and its honest price. The diagnosis is "fragmented runtime state":
transcripts, tool effects, memory events, workspace placement, branch provenance and
replay evidence recorded separately become hard to inspect or reproduce, and
**compression can discard evidence with no record of what was removed**. The fix is a
first-class `Session` value — branchable, inspectable, replayable, backend-aware,
composable — carrying conversation chunks, sandbox placement, lineage metadata, token
usage, pending work and tool evidence, with `Sandbox`, `Tool`, `Agent`, `Memory`,
`Workflow` and `Selector` around it, so that "fork, merge, and replay become explicit
runtime operations rather than states reconstructed from external traces."

The decision-relevant part is the scope it declares for itself: the report presents the
programming model, architecture, audited milestones and evidence protocol, and states
that its claims "are limited to controlled runtime properties", leaving broad
quantitative comparisons, live-provider quality, optional-backend availability and memory
quality to follow-on evaluation.

## What it means for tezgah

The case for a session-as-runtime-value is currently an architectural argument with
audited milestones, not a measured win — the weakest possible footing for growing a
runtime on. tezgah's analogue of the Session is dispersed by design (`.tezgah/` research
lines, the lessons ledger, `plans/`), and this note argues for keeping it that way.

The one thing worth taking is the *evidence record*: OpenRath names the exact loss that
"return the model input together with a record of anything omitted, truncated, or
compacted" prevents. That sentence is also in the surveyed repository's own README
(`README.md:36`) — and there it is declared and never populated
(`harness/contextbuilder/builder_test.go:181-183`). tezgah's `budgeted`/`_drop_note`
(`hooks/tezgah_context.py:702-752`) is the only place in either system where a drop is
actually recorded, which is why this line's verdict is "make tezgah's existing record
typed", not "adopt theirs".
