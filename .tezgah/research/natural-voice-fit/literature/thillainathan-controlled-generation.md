# Thillainathan and Koller 2024, fine-grained controllable generation (arXiv 2406.11338)

**What it is and claims.** Naming a target (write for grade 8) half-fails; decomposing it into checkable features and validating with a feedback loop reaches 81% exact match against 58.3% for a fine-tuned baseline.

**How it changes the skill.** The register brief must be a checklist of features the draft is validated against, which is also the only version our experiment can score.

**Quality.** Formal: peer-reviewed or an arXiv record, verified against two sources.
