# 2606.10106 — What makes a harness a harness: necessary and sufficient conditions for an agent harness

arXiv: https://arxiv.org/abs/2606.10106 — Sanderson Oliveira de Macedo (single author) —
2026-06-08, cs.SE / cs.AI. Abstract fetched through the arXiv API; the same record is in
OpenAlex as https://openalex.org/W7164154356.

## What it is
This is the definitional source. It starts from the observation that "agent harness" is
polysemous - the whole product sometimes (Claude Code, Codex CLI), the evaluation scaffold
other times (the SWE-bench harness), and often conflated with a framework, an SDK, an IDE
plugin or an orchestrator - and builds a *constitutive* definition: the necessary and
sufficient conditions for a system to be an agent harness, operationalized as an
inclusion/exclusion test. It reconstructs the term's genealogy from the horse's tack, through
the classic test harness, to the ML evaluation harness, to the agent harness.

The exclusion list is exactly the one this line's page has to answer to: **agent framework,
agent SDK, IDE plugin, eval harness, orchestrator**. The test is applied to six real harnesses
(Claude Code, Codex CLI, Aider, Cline, OpenHands, SWE-agent) and to deliberate edge cases, with
the claim that it includes and excludes consistently. It closes with a research agenda on
design-tension axes.

## Why it is in this line
It is the ruler. Every other note here says what some system does; this one says what makes a
system count as an agent harness at all, and it is the source the boundary page's exclusion list
is taken from. Its method also matters to the page's honesty: the definition was built to be an
instrument that decides cases, which is what a boundary page has to be rather than a list of
opinions about the word.

## Quality and limits
Formal by class (a preprint on arXiv with a single stated author and a method), but the method
is conceptual analysis over "works with persistent identifiers and primary grey-literature
sources", so the result is an argued definition and not a measurement. No venue or peer review
is visible in the record read, and none of the six classifications was re-run here. Read in
this line as a vocabulary source, not as evidence about any named system.
